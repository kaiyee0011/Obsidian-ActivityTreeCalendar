# Changelog

## 1.1.0

- Select today and show the current month whenever the calendar is opened from the ribbon or command palette.
- Follow the new local day across midnight, month/year boundaries, and app focus after sleep when today is selected.
- Preserve manually selected historical dates during refreshes, including selections made just after midnight.
- Add a hand-drawn download history chart to both READMEs, with daily updates through GitHub Actions and a September 14, 2026 release baseline.

## 1.0.0

- Add a monochrome monthly activity heatmap with week numbers.
- Show edited Markdown files in a collapsible, path-compressed folder tree.
- Add Chinese and English interfaces that follow the Obsidian locale.
- Add a configurable darkest-heat threshold, defaulting to 10 edited files.
- Use a consistent light-purple label for today's date.
